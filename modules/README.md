# Modules

This directory contains the refactored modules for the application. Each module is designed to be a self-contained unit that can be easily reused and maintained.

## Auth

The `auth` module provides a generic authentication interface that can be used with any authentication provider.

## Google Calendar

The `google-calendar` module provides a set of functions for interacting with the Google Calendar API.

## Stripe

The `stripe` module provides a set of functions for interacting with the Stripe API.
